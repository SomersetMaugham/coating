# Coating Studio v1 — 구현 계획 (개정판 r2)

> r1 계획에 외부 검토(Argon) 의견과 사용자 결정을 반영한 판입니다. 이후 바뀐 설계는 해당 장에 "v1 이후 추가"로 요약하고,
> 경과는 `DEVELOPMENT_HISTORY.md`에 적습니다.

## 목적과 범위
- 다목적 코팅 시뮬레이터의 첫 버전입니다. v1은 **전파 흡수체(레이더·마이크로파, GHz 대역)**를 다룹니다.
- 엔진은 범용으로 설계해서, 이후 광학 코팅(복사 냉각, 반사방지)으로 확장할 수 있게 합니다.
- Windows, Linux, macOS에서 동작합니다.
- GUI는 상용 프로그램 수준의 PySide6 앱이고, 한국어와 영어를 지원합니다.
- 저장소는 `SomersetMaugham/coating`(MIT), 이름은 Coating Studio입니다.
  - 패키지: `coating_studio`
  - 실행 명령: `coating-studio`

## 1. 물리 엔진 (`coating_studio.core`, GUI 의존성 없음)
- **내부 단위**: SI 단위(Hz, m, Ω)로 계산합니다. 화면 단위(GHz, mm, °, Ω/sq)와 향후 광학 단위(µm, nm, n·κ)는 `units`·어댑터 계층에서 변환합니다.
  - v1 이후: 스펙트럼 축은 프로젝트마다 GHz·THz·진공 파장(µm·nm)·파수(cm⁻¹) 중에서 골라 그래프·입력·문구·내보내기·보고서에 씁니다(표시 전용,
    `core/units.py`·`spectral.py`, 개발 이력 3.21). 재료 모델 파라미터와 CLI 수치는 그대로입니다.
  - v1 이후: 두께는 프로젝트마다 mm·µm·nm 중에서 골라 층 스택·속성·최적화·보고서에 씁니다(표시 전용, 스펙트럼 단위와 독립,
    `lengths.py`, 개발 이력 3.22). CLI 수치와 최적화 변수 경로의 단위는 mm 그대로입니다.
  - v1 이후: 스윕 점 간격은 주파수 등간격·진공 파장 등간격·로그 중에서 고릅니다(`SweepSettings.uniform_wavelength`, 스키마 7, 개발 이력 3.23).
    최적화 목표의 격자는 주파수 등간격 그대로입니다.
- **규약**: 공학 관례인 e^{jωt}, ε = ε′ − jε″, μ = μ′ − jμ″를 씁니다.
- **해법**:
  - 임피던스 재귀(전송선 등가)로 Γ와 입력 임피던스를 구합니다. 발산하는 지수 항은 쓰지 않습니다.
  - TE와 TM 사입사를 지원합니다.
  - 주파수 × 각도는 NumPy 브로드캐스팅으로 벡터화합니다.
- **복소 제곱근**: `k_z`는 전용 함수로 구합니다. 모든 층에서 Im(k_z) ≤ 0을 강제합니다(감쇠파와 소산파 모두).
- **구조**: 입사 매질 → 층 목록 → 뒷면입니다.
  - 층 종류:
    - 슬래브 층: ε(f), μ(f), 두께, 밀도
    - 저항 시트: 복소 Z_s [Ω/sq]
  - 뒷면 종류:
    - PEC
    - 반무한 매질
- **층별 흡수**: 계면 전압 비율을 순방향으로 전파합니다(비율 형태라 오버플로가 없음). 그다음 계면마다 포인팅 전력을 차분해 흡수를 구합니다.
  - 저항 시트의 흡수는 별도 항목으로 집계합니다.
  - 결과가 R + T + ΣA = 1을 만족하는지 검증합니다.
- **출력**:
  - |Γ|, |Γ|², T, A, 층별 A, Z_in
  - TE, TM, 평균 각각
- **RL 표시**: 내부 계산은 20·log10|Γ|(음수)입니다. 화면 표시는 설정에서 음수 dB(기본)와 양수 dB를 전환할 수 있습니다. 라벨에 '낮을수록 우수' 또는 '높을수록 우수'를 함께 표기합니다.

## 2. 재료 (`coating_studio.materials`)
- **모델**:
  - 상수 복소 값
  - 다항 Debye
  - Lorentz
  - 전도도 항 σ
  - 페라이트: Snoek형 완화, 자기 Lorentz 공명
  - 측정 CSV (f, ε′, ε″, μ′, μ″): 선형 보간합니다.
- **실효 매질 혼합**: Maxwell-Garnett와 Bruggeman 모델을 지원합니다. 기지 재료와 충전 재료, 체적 분율로 정의하며, 체적 분율은 최적화 변수로도 쓸 수 있습니다.
- **충전재 유효 파라미터 역산**: 복합재 한 시편의 측정값, 기지 물성, 함량, 혼합 모델에서 충전재의 유효값을 해석적으로 구해 혼합 재료의 충전재로 씁니다(`coating-cli invert-filler`, CLI_PLAN 13.9). 혼합 모델에 묶인 값이며, 따로 측정한 물성이 아닙니다.
- **CSV → 분산 모델 피팅**: 측정 데이터에서 Debye/Lorentz 파라미터를 최소자승으로 추출합니다. 피팅 품질 지표(잔차)를 보여 줍니다.
- **검사**:
  - 수동성 검사: ε″ < 0 또는 μ″ < 0이면 경고합니다.
  - 현실성 경고: Snoek 한계 초과나 비현실적 ε 같은 값에 경고를 띄웁니다.
- **재료 라이브러리**: 사용자 라이브러리를 JSON으로 저장합니다. 몇 가지 대표 예제 재료를 기본 제공합니다.

## 3. 최적화 (`coating_studio.optimize`)
- **변수**:
  - 연속 변수: 두께, 시트 저항, 상수 ε·μ, 분산 모델 파라미터, 체적 분율. 사용자가 '최적화'로 표시한 것만 다루며, 상하한 지정이 필수입니다.
  - 이산 변수: 층별 재료(후보 목록에서 선택)
- **목적함수**: 정규화한 항목의 가중합입니다. 사용자가 항목별 기준값과 가중치를 지정합니다.
  - 대역 내 최악 RL
  - 평균 |Γ|²
  - 총 두께
  - 면밀도
  - 제약을 넘으면 페널티를 줍니다(총 두께 상한 등).
- **평가 격자**: 주파수 범위 × 입사각 범위 × 편파(TE/TM/둘 다)이며, 사용자가 정합니다.
- **알고리즘**:
  - 재료 조합 수가 64개 이하이면 조합을 전수 열거합니다. 각 조합에서 differential evolution을 돌립니다.
  - 조합이 많으면 후보를 대역 중심 임피던스 순으로 정렬한 뒤 정수 변수로 DE를 돌립니다.
  - 국소 정밀화는 L-BFGS-B로 하며, 최악값은 LogSumExp로 평활화합니다. 결과 보고는 실제 최악값으로 합니다.
- **사전 검증(pre-flight)**: 시작 전에 CSV 유효 범위, 상하한, 수동성을 검사합니다.
- **실행**:
  - QThread 워커에서 돌리고, Signal로 수치만 전달합니다.
  - 화면 갱신은 초당 최대 10회입니다.
  - 매 세대마다 중지 플래그를 확인해 즉시 멈출 수 있습니다.
  - 실시간 수렴 곡선을 보여 줍니다.
- **결과**: 최적 구조를 프로젝트에 적용하거나 새 프로젝트로 엽니다.

## 4. 제조 공차 분석 (`coating_studio.tolerance`)
- 층별 두께와 물성에 ±% 오차를 정규분포 또는 균일분포로 줍니다.
- 몬테카를로로 N회 실행합니다.
- RL–주파수 그래프에 중앙값 곡선과 백분위 음영 밴드(예: 5–95%)를 그립니다.
- 대역 내 목표 RL을 만족하는 수율(%)을 표시합니다.
- **v1 이후 추가된 설계** (경과와 근거는 `DEVELOPMENT_HISTORY.md` 해당 절):
  - 손실 공차: ε″·μ″에 실수부와 별도의 오차를 주어 손실 탄젠트도 변합니다(3.11). 실수부·손실 오차의 상관계수 ρ는
    프로젝트 기본값 하나(3.17)에 층별 값을 덮어쓸 수 있습니다(3.18, `per_layer[uid]["loss_correlation"]`, 스키마 6).
    층별 덮어쓰기는 난수 순서를 바꾸지 않아, 기본값과 같은 값을 주면 표본이 비트 단위로 같습니다.
  - 평가 각도는 세 가지입니다(3.15, 3.19). 기본은 **한 각도**(공차 설정의 입사각·편광·대역·목표)입니다.
    **목표 꼭짓점**은 사용 중인 목표마다 각도 범위의 양 끝 × 편광, **목표 각도 격자**는 최적화기와 같은 각도 격자
    (`BandTarget.grid()`, CLI는 `--n-angle`로 더 촘촘하게) × 편광에서, 그 목표의 대역과 목표값으로 평가하고 결합 수율을 냅니다.
  - 여러 각도 평가(`tolerance.run_tolerance_targets`)는 표본을 한 번 뽑고 각도마다 따로 풉니다. 그래서 모든 행이 같은 표본을
    보고, 각 행은 그 점의 단일 각도 분석과 비트 단위로 같습니다. 같은 구조를 모든 각도에 한꺼번에 풀면 더 빠르지만,
    이 같음을 플랫폼마다 보장할 수 없어 택하지 않았습니다.
  - 주파수 격자는 최적화기와 다릅니다(공차는 스윕 격자, 최대 301점). 격자 점 사이의 각도·주파수는 보지 않습니다.
  - 결과는 실행 당시 설정(깊은 사본)과 수율 판정 구간을 함께 저장합니다(3.20). 그래프와 보고서는 현재 설정이 아니라 이 값을 씁니다.
  - 설계 보고서는 HTML(`report.py`, 3.17) 또는 A4 PDF(`gui/report_pdf.py`, 3.24 — 같은 보고서의 인쇄용 변형을 Qt로 배치)로 내보냅니다.
  - 보고서에 공차 밴드 그래프를 넣습니다(3.20). 단일 각도 결과는 1개, 목표 꼭짓점·격자 결과는
    목표마다 최저 수율 행 1개(최대 6개, 수율 낮은 목표 우선). GUI 공차 탭과 같은 그리기 함수(`report.draw_tolerance_band`)를 씁니다.

## 5. GUI (`coating_studio.gui`, PySide6)
- **왼쪽 도크**: 층 스택 편집 표(추가, 삭제, 순서 변경, 최적화 표시)와 축척 단면 그림입니다.
- **오른쪽 도크**: 선택한 층·재료의 속성 편집기입니다.
- **중앙 탭**:
  - RL–주파수
  - RL–입사각
  - 주파수×각도 맵
  - Smith 차트
  - 층별 흡수
  - 재료 물성 ε(f)·μ(f)
  - 공차 분석
- **기타**:
  - 재료 라이브러리 관리자(CSV 가져오기와 피팅 포함)
  - 최적화 패널
  - 설정(언어, 테마, RL 부호)
- **Undo/Redo**: 층 스택·재료 데이터 모델 편집에만 적용합니다(QUndoStack).
- **파일**:
  - 프로젝트는 `.coat`(JSON, 스키마 버전 포함)로 저장합니다.
  - 최근 파일 목록을 둡니다.
  - 그래프는 PNG/SVG/PDF, 데이터는 CSV로 내보냅니다.
- **완성도 세부 사항**:
  - 라이트/다크 테마는 Matplotlib 스타일 동기화 헬퍼로 맞춥니다.
  - OS별 한글 폰트 폴백을 적용합니다(Malgun Gothic / Apple SD Gothic Neo / Noto Sans CJK KR·NanumGothic). `axes.unicode_minus = False`도 설정합니다.
  - 단축키, 상태 표시줄, 툴팁, 그래프 커서 판독을 제공합니다.
  - 창 상태를 기억합니다.
- **예제 프로젝트**: Salisbury 스크린, Dallenbach 층, 2층 Jaumann, 페라이트 타일, 카본/에폭시 혼합 층
- **다국어**: 한국어와 영어. 기본값은 OS 언어를 따르고, 설정에서 전환할 수 있습니다.

## 6. 패키징과 검증
- **패키징**: `pyproject.toml`, Python 3.10 이상, 의존성은 numpy, scipy, matplotlib, PySide6입니다.
- **pytest — 해석해 비교**:
  - 377 Ω Salisbury λ/4에서 Γ = 0
  - 단일 계면 Fresnel(TE·TM, Brewster 각)
  - 무손실 구조에서 R + T = 1
  - 손실 구조에서 R + T + ΣA = 1
  - Dallenbach 조건
  - 수직입사 TE = TM
  - 전반사·소산파에서 이득이 생기지 않음
  - 두꺼운 고손실 층에서 수치 안정성
- **pytest — 그 밖의 검증**:
  - Maxwell-Garnett·Bruggeman 극한값
  - 피팅이 합성 데이터의 원래 파라미터를 복원하는지
  - 최적화가 Salisbury 해를 재발견하는지
  - 프로젝트 저장·불러오기 왕복이 일치하는지
- **GUI 확인**: `QT_QPA_PLATFORM=offscreen` 스모크 테스트
- **CI**: GitHub Actions에서 ubuntu, windows, macos × Python 3.10, 3.13 매트릭스로 돌립니다. Linux에는 libegl1, libxkbcommon-x11-0, libxcb-cursor0 등을 설치합니다.
- **문서**: README를 한국어와 영어로 작성합니다(설치, 실행, 물리 규약, 예제).
- **v1 제외**:
  - PyInstaller 단일 실행 파일
  - 광학(복사 냉각) 모드
  - 비간섭 두꺼운 기판
